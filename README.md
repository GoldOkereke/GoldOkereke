## 🧠 Featured Project

### Stroke Shield — Multimodal AI for Pre-TIA Risk Detection

An AI system that detects early warning signs of stroke using:
- **PPG Signal Analysis** — 1D CNN for cardiac classification
- **Facial Asymmetry Detection** — MediaPipe for landmark analysis
- **Voice Pattern Analysis** — Librosa for speech feature extraction
- **Fusion Engine** — Combines all streams into a single risk score

Built with **Python, TensorFlow, FastAPI, React, TypeScript, and Docker**.
